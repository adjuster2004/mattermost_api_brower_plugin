# mattermost_api_brower_plugin - плагин для chrome, позволяющий экспортировать переписку из чата прямо в браузере

На случай, когда API закрыт на сервере MM

## 🛠️ Последовательность
- **Склонировать репозиторий**
```bash
git clone https://github.com/adjuster2004/mattermost_api_brower_plugin/
```

- **Открыть chrome://extensions/**
- **Переключиться в режим разработчика**
- **Загрузить распакованное расширение**
- **Открыть плагин на странице и нажать кнопку Открыть панель скрапера**
